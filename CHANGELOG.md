# Changelog

Все заметные изменения проекта документируются в этом файле.

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версионирование — [SemVer](https://semver.org/lang/ru/).

## [0.1.1] - 2026-11-11

### Fixed
- Уведомления теперь остаются в истории менеджера уведомлений (Plasma 6): вызов `Notify` дополняется подсказкой `desktop-entry`, а пакет поставляет `/usr/share/applications/swapnotif.desktop` — без них менеджер показывал баннер, но не сохранял уведомление, теряя его после исчезновения

## [0.1.0] - 2026-11-10

Первый релиз: демон мониторинга занятости swap с уведомлениями на рабочий стол и атрибуцией приложения-виновника.

### Added
- Мониторинг занятости swap с настраиваемым порогом (дефолт 80%), гистерезисом при возврате в норму и cooldown между уведомлениями (дефолт 5 мин)
- Определение приложения-виновника: наибольший прирост `VmSwap` за окно атрибуции (дефолт 60 с), группировка процессов по cgroup до уровня юнита; при недоступном пути cgroup — по имени процесса
- Уведомления на рабочий стол (`org.freedesktop.Notifications`) во все активные графические сессии; недоставленное событие повторяется, пока порог не сброшен
- Скорость обмена со swap (`pswpin`/`pswpout`) и процент занятости — в теле уведомления
- Работа «из коробки» без конфигурации; опциональный `/etc/swapnotif/config.toml` с fail-fast-валидацией — опечатка в ключе или значение вне диапазона дают явную ошибку запуска вместо тихих дефолтов
- deb-пакет: после установки сервис включён и запущен (systemd `Type=notify`, изоляция юнита), удаление пакета останавливает и отключает сервис
- Устойчивость: отсутствие swap — не ошибка, мониторинг возобновляется после `swapon` без перезапуска; завершение процессов и переиспользование PID не искажают атрибуцию
- CI: сборка deb и публикация GitHub Release по тегу `v*` с контролем совпадения тега и версии пакета
