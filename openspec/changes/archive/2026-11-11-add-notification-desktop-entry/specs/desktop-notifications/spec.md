# Spec Delta

## ADDED Requirements

### Requirement: Идентификация отправителя уведомления
The system SHALL передавать в каждом вызове `org.freedesktop.Notifications.Notify` подсказку `desktop-entry` со значением `swapnotif`, чтобы менеджер уведомлений связал уведомление с приложением и сохранил его в истории уведомлений сессии.

#### Scenario: Вызов Notify содержит подсказку desktop-entry
- **WHEN** демон доставляет уведомление в графическую сессию
- **THEN** вызов `Notify` содержит hint `desktop-entry` со значением `swapnotif`

#### Scenario: Уведомление остаётся в истории менеджера уведомлений
- **WHEN** менеджер уведомлений поддерживает резолв отправителя по `desktop-entry`, desktop-файл `swapnotif` установлен, и демон доставил уведомление
- **THEN** уведомление после исчезновения баннера остаётся в истории уведомлений сессии (не отбрасывается как уведомление неопознанного приложения)

#### Scenario: Иные hints по-прежнему не передаются
- **WHEN** демон доставляет уведомление в графическую сессию
- **THEN** вызов `Notify` не содержит hints кроме `desktop-entry` (кнопки действий, urgency, transient — вне скоупа)
